## 2026-10-24 · 桥改成「服务」：崩了秒级自愈，不再等 15 分钟

你会看到什么：

- Termux 上的桥现在由 **termux-services（runsv）** 监督：进程被系统杀掉/OOM/自己崩，**秒级**被拉回来
  （以前只有 termux-job-scheduler 每 15 分钟跑一次的 watchdog，Android 最小周期就那样）。
- 管它用 `sv`：`sv status pi-pocket` / `sv restart pi-pocket` / `sv down pi-pocket`。
  要**长期停用**就用 `sv-disable pi-pocket`（写 down 标记，watchdog 不会偷偷拉回；`sv-enable` 恢复）。
  单跑 `sv down` 只是临时停，watchdog 会在 15 分钟内按保活把它拉回来 —— 这是有意分工。
- 开机（装了 Termux:Boot）先起 runsvdir，再 `sv up pi-pocket`；Termux 应用被系统杀掉时仍由 watchdog 兜底。
- app 的「强制重启桥」与桥的 `POST /v1/restart` 都改走 `start-bridge.sh`：有服务就 `sv restart`，没服务才直起。

为什么改：用户 2026-10-24「pi pocket 的桥做成服务吧」。原来靠 `termux-job-scheduler` job 8899 每 15 分钟探一次，
桥崩了最多 15 分钟才回来（且 job 会在重装/升级后悄悄丢）。runsv 在 Termux 里已有（sshd 就是这么跑的）。

顺手修掉的债：`start-bridge.sh` 不再用 `pkill -f 'bin/pi-pocket-bridge$'` 做命令行名称匹配（
`docs/AUDIT-2026-10-23.md` 第 143 条记的正是这条），直起路径交给启动器按 `/proc` 核实的精确 PID 收归。

怎么试：`sv status pi-pocket` → `run:`；`kill -9 <桥 pid>` 后 1–3 s 内新 pid 起来、`/v1/health` 200；
`sv restart pi-pocket` 换进程；`sv down pi-pocket` 停住不再自拉，`sv-enable pi-pocket` 恢复。

## 2026-10-23 · 浅色模式对比度改成"按每个元素自己的底色"算

**现象**（你的第 3 张截图）：彩条上的白字被压成灰、看不清；而我原本只想压暗"白底上的浅灰字"。

**根因**：第一版是"凡是偏亮的前景色一律压暗"——它只考虑白底。
于是 `color:#fff` 落在深红/黄彩条上的标签也被压成灰，反而更难读。

**改法**：按元素**实际底色**（往上找第一个不透明背景；半透明按 50% 以上近似）分别处理：
- 底色亮（L > 0.179）且字太浅 → 压暗；
- 底色暗（L ≤ 0.179）且字太暗 → 提亮；
- 已经 ≥4.2:1 → 完全不动。
0.179 是"黑字与白字对比度相等"的分界点；原来用 0.35 当地色阈值，中绿（#3fb27f，L≈0.34）
被误判为暗底，白字原样保留 ⇒ 2.5:1。

**实测**（像素采样，浅色模式）：
- 深红条上的白字 `<40`：**6.54:1**
- 绿条上的 `60–90 最理想`（原白字）：改成深色后 **4.21:1**

## 2026-10-23 · 真正的原因：html 高度被多除了一个 density

**现象**：手机（density 4）上正文里的 html 只露出最上面一小条，剩下的完全不见。
**根因**（这轮才找到，之前两版都在外围打转）：
WebView 里写了 `<meta name="viewport" content="width=device-width, initial-scale=1">`，
所以页面报回来的 `scrollHeight` 已经是 **CSS px = dp**；app 又按 `px / density` 换算成 dp，
于是**块高度只有内容的 1/4**（手机 density 4）、1/1.75（模拟器）。模拟器上看起来"只是矮一点"，
所以一直没被当成主因。

**改法**：`htmlVisualHeightDp(cssPx, maxDp) = cssPx.coerceIn(48, maxDp)` —— 不再除 density；
上限仍是 2400dp。加了单测把这条钉住（1026 → 1026）。

**为什么前两版没解决**：限高（640dp）和量高口径（`scrollHeight` vs 窗口高）确实也是问题，
但它们只影响"内容比窗口高"的情形；density 除法在**所有** html 块上都在截断，量级更大。

- 顶部一张「当前模型」卡片（含**上一个 / 下一个**两个圆形按钮，就是终端里的快切）；
- 下面一个 M3 搜索框：**能搜型号也能搜厂商**，空格分词（`deep seek` 也能搜到 `deepseek`），带清空按钮；

- 名字最多两行（以前一行放不下就只剩省略号，`claude-sonnet-4-5` 和 `-4-5-20250929` 分不清）。

### 2. 修掉"文字重叠"（真 bug，影响所有面板）
不是排版难看，是**结构错了**：所有弹出面板的内容都被一层"可选中"容器包着，
而那层容器会把多个子元素**叠在同一位置**。所以模型列表、当前模型、搜索框全挤在一起。
现在先包一层纵向容器再交给选区容器 —— 该能长按复制的地方照样能复制，但不再重叠。
（设置、连接、思考等级等所有面板一起受益。）

### 3. 流式输出改成逐字显现
以前是一批一批蹦出来（模型吐一段、界面跳一下）。现在：
- 正在写的那条回答**逐字出现**，滚动跟着每帧微调，看着像在打字；
- 速度**跟着积压量走**：积压少时 1 字/帧，积压多时加速，永远在 ~0.3 秒内追上真实内容
  （固定速度会越跑越落后，最后"模型早答完、界面还在吐字"）；
- 积压超过 1200 字直接显示全文（切后台回来那种情况，不再假装打字）；
- 历史消息不参与动画，打开旧会话不会一堆字乱蹦。

## 2026-10-22 · 能用 `!` 跑命令、顶栏显示 git 分支、命令/分叉记录不再丢

### 1. 输入框里打 `!` 就是跑命令（跟终端一样）
- `!ls -la` → 在本会话目录里执行，结果**记进会话**（对话里能看到那条命令和输出）；
- `!!ls` → 同样执行，但**不进对话上下文**（只想看一眼用）；
- 一打进 `!`，输入框边框立刻变**绿色**，占位文字变成「运行命令…」，右侧会显示 `exit 0`。

以前手机上想跑个命令得进「命令执行（Shell）」那个独立页面，而且输出不会留在对话里。

### 2. 命令卡 / 分支摘要在对话里显示了
- 你在终端敲过的 `!cmd`，回到手机现在能看到（以前直接被丢掉）；
- 分叉时带摘要的会话，会出现一张「分支摘要」卡（点开看内容）。

### 3. 顶栏多了 git 分支
标题下面第一段会显示 `(main)` 这样的分支名（终端 footer 的 `~/proj (main)` 那段）。
不在仓库里就不显示；detached HEAD 显示 `(detached)`。

### 怎么试
在输入框打 `!ls`，看边框变绿 → 回车，对话里出现一条 `$ ls` 的命令卡，点开看输出；
换个仓库里的会话，顶栏应出现 `(分支名)`。

## 2026-10-22 · 会话树、行为开关、断线自愈、看得见的 read

### 1. 会话能分支了（以前完全做不到）

点任意一条**你说过的话** → 「分叉」→ 就从那里切出一个**新会话**，
而且那句话会自动回到输入框，你可以改一改再发（跟终端里的 `/fork` 一样）。
面板底下还有「**复制当前会话**」：等于把这整条会话复制一份，随便折腾不影响原来那份。

### 2. 「行为开关」——终端里能调的那几项，手机上也能调了
会话菜单新增「**行为开关**」：

- **自动压缩上下文**：聊太长会不会自动压一压；
- **自动重试**：模型出错会不会自己重来（还会告诉你它配的上限次数）；
- **插入方式 / 排队方式**：你在一轮进行中发消息，是「一次一条，等它回完再发下一条」，
  还是「一起送进去」。

改完立刻生效，不用重启。**正在自动重试时**，输入框上方会多一行
「重试中（2/5），4.0s 后自动重来」，旁边有个「**中断**」——以前只能干等或去终端按 Esc。

### 3. 桥断了会自己接回来（以前要手动点「拉起」）

查下来**桥其实一直是活着的**（日志里 80 多次“拉起”，每次都是“已有桥在跑”）——
是 app 自己放弃重连了。

现在的行为：
- 断线后**自己重试**，间隔逐渐拉长（1 秒 → 30 秒封顶），不用你管；
- 连续几次连不上，**自己把 pi 拉起来**（不用再点按钮）；
- 你一回到 app，它**立刻重新探一次**；
- 更阴的情况也修了：桥还活着、但事件通道已经僵死（界面显示“已连接”却什么都不动）——
  现在会自己发现并重建。

### 4. `read` 读出来的东西，现在都能点开看
以前工具读了文件，只有**图片**能点开看，读文本就只能在卡片里看被截断的两行。
现在每张 `read` 卡片下面都有一行可点的入口：

- 读的是图 → 「**查看图片** /路径」
- 读的是文本 → 「**查看内容** /路径」

点开就是完整内容（能滚动、能选中复制）。

灰 → 蓝 → 蓝紫 → 紫 → 品红 → 红，越往后思考越用力。

模拟器原来只有 4 核、3G 内存、纯软件画图；现在 6 核 / 6G / 用真显卡画，
