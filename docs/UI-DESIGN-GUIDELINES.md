# 菜单与设置设计规范

更新：2026-10-23。此文是项目当前约定；视觉验收记录由维护者在内部流程维护。后续学习到的规则应在这里更新，保留来源、适用范围和验证方法，不只留在聊天或代码注释里。

## 已查证的官方依据

| 来源 | 可据此执行的要求 | 适用边界 |
| --- | --- | --- |
| [Android Compose accessibility defaults](https://developer.android.com/develop/ui/compose/accessibility/api-defaults) | 可交互目标至少 48dp；带文字的开关把 toggleable 放在父行，子 Switch 的 onCheckedChange=null，整行只有一个切换动作 | 48dp 是触摸目标下限，不是所有列表必须固定 48dp 高 |
| [Compose menus](https://developer.android.com/develop/ui/compose/components/menu) | 使用 DropdownMenu/MenuItem 的锚定和标准交互；长菜单可以滚动，示例不会惰性创建条目 | 官方没有“最多七项”的普遍限制；不得写成 DropdownMenu 无法滚动 |
| [Compose bottom sheets](https://developer.android.com/develop/ui/compose/components/bottom-sheets) | ModalBottomSheet 的可见状态、关闭回调和组合生命周期应一致 | “同一时刻只渲染一个设置面板”是本项目导航取舍，不是官方禁止叠层的原文 |
| [Material Android menu implementation](https://github.com/material-components/material-components-android/blob/master/docs/components/Menu.md) | 菜单由文本、可选图标/尾部信息、分隔线构成；使用主题色和文本角色 | 这是 Android View 实现参考，不据此推导 Compose Expressive 的精确圆角数值 |

Material 官网 [菜单](https://m3.material.io/components/menus/guidelines) 和 [列表](https://m3.material.io/components/lists/guidelines) 是规范入口；本次网页正文依赖 JavaScript，具体条款以上述可读取的官方 Android 文档为核查依据。旧设计记录中的数值应理解为当时依赖版本或项目选择，不应泛化为永久规范。

## 项目选择与组件责任

- 快捷菜单保持七个高频入口是产品约定；低频动作进入可滚动、按会话/工具/设置分组的“更多”。“全部设置”必须可发现，注入设置仍保留直达入口。
- 菜单当前值（模型/思考等级）置于次级文字，给文字分配剩余宽度，避免与箭头争抢空间。更多列表最小高度 56dp，可随两行标题增长，不固定高度截断。
- 设置首页提供概览，按“连接与模型 / App 与显示 / 维护 / 当前会话”分组；长表单放独立子页。当前会话操作仅在目标存在时显示，并确认明确目标。
- SettingsGroup 管分组标题、容器主题色与外边距；SettingsRow 管标题、说明、整行点击和导航箭头。使用 Material typography/color/shape 角色，不在各页重新发明配色或字号。
- 设置行最小高度 64dp，说明文字可换行；这两个数值是当前密度选择。开关行整行可点、语义角色为 Switch，加载/保存期间禁用，防止重复请求。
- 根设置页关闭回原页面；由设置进入的子页，返回先回设置；从聊天直接进入注入页，关闭回聊天。导航状态只选择一个设置面板，避免覆盖和穿透。
- 继续使用项目现有接近全高的底部面板；内容滚动，标题和关闭/返回可见。窄屏、横屏和大字号不能通过强行缩字解决。全高设置与更多面板显式继承调用处 density；其他类型弹窗的自定义字号继承尚需专项核查，不能泛称所有弹层均已修复。

## 数据与反馈

- 点击入口先导航，再异步加载；网络失败不能表现为入口无反应。
- 首次加载、保存、失败、无数据/能力关闭分别显示。已有数据时保存错误仍必须可见；重试不会暗中恢复默认。
- 保存成功以桥返回值为准，不提前翻转开关。切换机器或凭据后清除旧资料；迟到的旧请求结果不能写进新连接。
- “重新连接”调用真实重连并在首页显示连接状态/状态消息。执行动作不使用暗示下级页面的箭头。
- 重启桥、重载会话、恢复默认需要说明影响和确认。组件更新当前支持下载；旧安装脚本尚未迁移为精确 PID、事务替换和可恢复流程，App 不提供调用入口，避免误导。

## 变更验收清单

1. 单测导航序列：设置→注入→返回→设置→关闭；聊天直达注入→关闭；切换同级页不堆栈。
2. AVD pipocket-qa + mock：从可见入口实际点进设置/注入；点击文字行也能保存；重新打开保持桥返回状态。
3. 模拟保存失败：保留旧值、显示失败和重试，不能静默；加载/保存中不得重复操作。
4. 浅色/深色、大字号（项目全局 1.6）、竖屏/横屏检查：标题、模型摘要、说明、返回按钮、底部按钮不互相覆盖，长内容可滚动到底。
5. 截图进 docs/screenshots；记录实际执行的条件，未执行的矩阵项明确标记，不以编译通过代替视觉验收。只在模拟器测试，实机仅安装。
6. 独立审查者自读代码/diff/原始截图和日志，附 audit 段；实现者的自测不替代独立审查。
