01

All sessions, grouped by project所有会话，按项目分组

The list is the workspace: project directories become groups, and each card carries the path, relative time and transcript size. Grouping, sorting, time and project filters are one tap away.

列表就是工作区：项目目录自动成组，每张卡带路径、相对时间与转录大小；分组、排序、时间和项目筛选都只需一次点击。

  • Group by directory or time bucket
  • Sort by updated, created or name
  • Pinned sessions keep a small amber dot
  • New session asks the bridge for a working directory
  • 可按目录或时间桶分组
  • 可按更新、创建或名称排序
  • 固定会话带一个琥珀色小点
  • 新建会话时向桥选择工作目录
02

Thinking, tools and answers in one column思考、工具与回答在同一列

User turns are blue blocks. Thinking is italic grey. Tool calls collapse into green cards. The answer renders in the terminal's Markdown voice, not a generic chat bubble.

用户消息是深蓝块，思考是灰色斜体，工具调用折叠成绿色卡片；回答按终端的 Markdown 口径渲染，而不是通用聊天气泡。

  • Amber headings; H1 keeps an underline
  • Purple list markers and inline code
  • Thinking collapses to one line and remembers its state
  • The context ring sits above the composer
  • 标题为琥珀色，H1 带下划线
  • 列表符号与行内码为紫色
  • 思考可折叠成一行，并记住展开状态
  • 上下文环固定在输入区上方
03

Tool output stays inspectable工具输出仍然可查

Success is green, failure is red, a running call is grey. Long output is clipped and expandable; images and text files expose an explicit open action instead of dumping raw JSON into the conversation.

成功是绿色、失败是红色、运行中是灰色；长输出默认折叠可展开，图片和文本文件给明确的“查看”入口，而不是把原始 JSON 倒进对话。

  • bash keeps exit_code and the error message
  • Image results get a “查看图片” action
  • Text reads get a “查看内容” action
  • The whole card inherits the terminal tool palette
  • bash 保留 exit_code 与错误信息
  • 图片结果有“查看图片”入口
  • 文本读取有“查看内容”入口
  • 整张卡片沿用终端工具配色
04

Tables and diagrams, measured表格与图，按真实宽度排

CJK column widths are measured from real glyph width, not guessed. Wide tables scroll horizontally; Mermaid renders locally from the packaged runtime, with no CDN request.

中文列宽按真实字形宽度测量，不靠猜；宽表横向滚动；Mermaid 用本地打包的运行时渲染，不请求 CDN。

  • Square hairline borders, like the terminal
  • Wide tables keep every column readable
  • Vertical diagrams are not clipped
  • Code blocks and rules use the same palette
  • 与终端一致的方角细线边框
  • 宽表保持每列可读，不被挤压
  • 竖向长图完整显示，不被截断
  • 代码块与分隔线沿用同一套配色
05

Know what the turn costs知道这一轮花了多少

Tap the ring for a breakdown of system prompt, messages and tool output, plus input/output tokens, cache traffic and spend. The ring turns amber at 60% and red at 85%.

点上下文环可看系统提示、消息与工具输出的占比，以及输入/输出 token、缓存流量和花费；60% 变琥珀、85% 变红。

  • Green under 60%, amber 60–85%, red above 85%
  • Shows model and thinking level
  • Compaction can be triggered early
  • Session info is one tap deeper
  • 低于 60% 绿色，60–85% 琥珀，高于 85% 红色
  • 同时显示模型与思考等级
  • 可提前触发上下文压缩
  • 再点一次进入会话信息
06

Slash commands without leaving the composer不离开输入区就能用斜杠命令

Type / or tap the slash button. The menu has two stages: command, then arguments. Full-width ／ is normalised, and the hint explains what each command changes.

输入 / 或点斜杠按钮即可。菜单分两段：先选命令，再选参数；全角 ／ 会自动归一化，提示会说明每条命令改什么。

  • /model switches the model for this session
  • /mode changes permission mode
  • /compact compacts the context
  • Arrow keys and Enter work in the menu
  • /model 切换当前会话模型
  • /mode 切换权限模式
  • /compact 压缩上下文
  • 菜单里可用方向键与回车

The mock bridge advertises three commands; a real pi bridge exposes its full command list.

假桥只声明了三条命令；真实 pi 桥会列出完整命令表。

07

Switch machines, wake one over SSH切换机器，SSH 唤醒

Loopback, LAN and Tailscale hosts in one picker. The app merges multiple routes to the same host, remembers the best path, reads SSH config, and can bootstrap a blank Termux from zero. On Termux the bridge is installed as a runsv service, with a watchdog fallback.

本机、局域网与 Tailscale 主机都在一个面板里；同一台机器的多条路径会合并，记住最优路径，读取 SSH 配置，还能从零部署空白 Termux。Termux 上桥会装成 runsv 服务，并由 watchdog 兜底。

  • Bridge URL, token state and reachability
  • Scan loopback and the current subnet
  • Read host SSH config or the bridge host's config
  • Bootstrap a blank Termux, then let runsv supervise the bridge
  • 显示桥地址、token 状态与可达性
  • 扫描本机与当前网段
  • 读取手机或桥主机的 SSH 配置
  • 空白 Termux 一键部署，桥交给 runsv 监督
08

Run a command on the connected host在已连接主机上执行命令

The Shell tab posts to /v1/bash and streams output over SSE. Commands can be marked out of context, so a quick diagnostic does not spend tokens.

Shell 页调用 /v1/bash，输出通过 SSE 流回；命令可以标记为不进上下文，快速排查不烧 token。

  • Header shows the host behind the bridge
  • Exit code is visible after each run
  • Recent commands stay as chips
  • “不进上下文” keeps diagnostics out of the prompt
  • 标题显示桥所在主机
  • 每次执行后显示退出码
  • 最近命令保留为快捷 chip
  • “不进上下文”避免诊断命令占用提示词
09

Light, dark, or follow system浅色、深色或跟随系统

Material You dynamic colour on Android 12+, baseline palette below. Text size is a global multiplier layered on the system font scale; the terminal palette keeps its contrast in both themes.

Android 12+ 使用 Material You 动态取色，低版本回落到基线配色；字号是叠加在系统缩放之上的全局倍率，终端配色在明暗两套主题里都保持对比度。

  • System, light or dark, persisted per device
  • Status bar icons follow the app theme
  • Global and chat-only text scaling
  • Amber, purple and green keep their meaning
  • 跟随系统、浅色或深色，按设备持久化
  • 状态栏图标跟随 app 主题
  • 全局字号与对话字号两级倍率
  • 琥珀、紫、绿的语义保持不变

这些图怎么拍的。720×1600 的 AVD pipocket-qa + tools/mock-bridge.mjs。假桥应答 health、sessions、转录、Shell 与上下文请求；没有真实 pi 进程、模型或个人信息参与。所有名称、路径与会话均为合成；出现的 IP 仅为本地地址：10.0.2.2（模拟器宿主机别名）与 127.0.0.1（回环）；没有真实地址。
