Pocket Pi is an Android client for pi running inside Termux on the same phone — or on any machine you can reach over LAN or Tailscale.

Pocket Pi 是 pi 的 Android 客户端：pi 跑在同一台手机的 Termux 里，也可以连局域网或 Tailscale 上的任意机器。

No remote desktop. No cloud relay. A native Compose interface talks HTTP + SSE to a small bridge that drives pi --mode rpc and keeps a real session on disk.

不是远程桌面，也没有云中转。原生 Compose 界面通过 HTTP + SSE 连接一个小桥；桥驱动 pi --mode rpc，并把真实会话留在磁盘上。

Why another client为什么再做一个客户端

The terminal is the engine.
The phone is the interface. 终端是引擎，
手机是界面。

Pocket Pi does not reimplement the agent. It gives pi a native mobile surface while keeping sessions, tools and prompts in the same place they already live.

Pocket Pi 不重写 Agent，只给 pi 一个原生手机界面；会话、工具与提示词仍留在原来的位置。

Runs on the phone就在手机里跑

Termux hosts the bridge and a real pi process. The app connects to 127.0.0.1 — no laptop in the loop.

Termux 承载桥和真正的 pi 进程，app 连接 127.0.0.1，不需要一台电脑中转。

Terminal-parity render终端口径渲染

Amber headings, purple inline code, blue links, green tool blocks and square tables — measured against the pi TUI, not invented.

琥珀标题、紫色行内码、蓝色链接、绿色工具块与方角表格——对照 pi 终端实测，而不是凭空设计。

Built for long turns为长回合设计

流式增量、可折叠思考、工具实时状态；运行中可 steer 或排队，随时停止，断线自动重连。

Architecture架构

One bridge. One session file. No proprietary store.一个桥，一份会话文件，不锁进专有存储。

The app is a client. The bridge is a transport. pi remains the agent, and its JSONL sessions remain the source of truth.

app 是客户端，桥是传输层；pi 仍是 Agent，JSONL 会话文件仍是唯一事实来源。

Pocket Pi appKotlin · Compose · Material 3
⇄
Termux bridgeTermux 桥Node · HTTP + SSE
pi --mode rpcJSONL over stdio
⇄
~/.pi/agent/sessionsone JSONL per session每个会话一个 JSONL

The bridge can also live on a LAN or Tailscale host. The app probes loopback first, then the current /24, then saved machines. If the bridge is down, the app can SSH in and start it.

桥也可以跑在局域网或 Tailscale 主机上。app 先探测本机，再扫当前 /24，最后试已保存机器；桥没起时可以 SSH 进去拉起。

Quick start快速开始

Bridge in Termux, build the app.在 Termux 起桥，构建 app。

Prerequisites: Termux with Node 20+, a working pi install, and an Android SDK for the APK. The app is debug-signed; there is no store release yet.

前置条件：Termux 与 Node 20+、可用的 pi、以及用于打包的 Android SDK。app 目前是 debug 签名，尚未上架商店。

1 · Termux bridge1 · Termux 桥
# inside Termux
pkg install nodejs git
git clone https://github.com/OhiyoX/pi-pocket.git
cd pi-pocket
./termux/install.sh
termux-wake-lock
nohup pi-pocket-bridge >> ~/.pi/agent/pi-pocket-bridge.log 2>&1 &

# verify
curl -s localhost:8789/v1/health
2 · Android app2 · Android app
# on the build machine
./gradlew :app:testDebugUnitTest :app:assembleDebug

# install on a connected device
adb install -r app/build/outputs/apk/debug/app-debug.apk

# first launch: allow Termux RUN_COMMAND
# Termux ~/.termux/termux.properties
allow-external-apps=true

Remote host? Start the bridge with PI_POCKET_HOST=0.0.0.0 and a token, then add the URL or the SSH target in the machine sheet. The app pins the host key on first connect. 连远端？用 PI_POCKET_HOST=0.0.0.0 和 token 启动桥，然后在机器面板里填 URL 或 SSH 目标；首次连接会固定主机密钥。

Security and limits安全与边界

Small surface, stated plainly.边界写清楚，不夸大。

Pocket Pi is designed for a personal device and a trusted network. These are the boundaries the current build actually enforces.

Pocket Pi 面向个人设备与可信网络；以下是当前构建真实执行的边界。

  • Loopback by default; a non-loopback bind refuses to start without PI_POCKET_TOKEN.
  • SSH host keys are pinned on first connect; a changed key is rejected.
  • The bridge only transports and attributes events. It does not proxy model traffic through a third party.
  • No analytics, no telemetry, no cloud relay. This Pages site makes no external requests.
  • Current builds are debug-signed. Treat the APK as a development artifact, not a store release.
  • Tokens and SSH credentials live in app preferences unencrypted. Use a device lock and a dedicated token.
  • Android loopback is not an app isolation boundary: another app on the same device can reach the bridge. Set a token if that matters.
  • 默认只绑回环；非回环绑定没有 PI_POCKET_TOKEN 会拒绝启动。
  • SSH 主机密钥首次连接即固定，之后密钥变化会拒绝连接。
  • 桥只搬运并归属事件，不把模型流量转给第三方。
  • 无统计、无遥测、无云中转；这个 Pages 站点不请求任何外部资源。
  • 当前构建是 debug 签名，请当作开发产物，不是商店发布版。
  • token 与 SSH 凭据存在 app prefs 里，未加密；请使用设备锁和专用 token。
  • Android 的回环不是应用隔离边界：同机其它 app 也能连桥。介意就设 token。
